# Earth texture

Earth surface image distributed by the Three.js examples:
https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg

Source imagery: NASA Blue Marble (public-domain Earth imagery).
Downloaded 2026-09-15. Served locally; viewing the texture does not contact the source server.

## Dotted globe land source

Elevation map from the three-globe examples (NASA-derived Earth topology):
https://raw.githubusercontent.com/vasturiano/three-globe/master/example/img/earth-topology.png

Sampled locally to place dots over land. This asset is not a visitor-location dataset.
